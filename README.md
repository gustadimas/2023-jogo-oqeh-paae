# O que é, PAAE

Atividade da faculdade de out/2023 a nov/2023. Publiquei anos depois (nov/2026) e não atualizei nada.

Jogo de decisões que fiz em Construct 3 em outubro de 2023. Tem menu, regras, configuração de volume, créditos e três personagens (Sarah, Matheus e Alisson). Cada um tem uma introdução, uma tela de decisão e o resultado de acerto ou erro.

Em novembro comecei a refazer o jogo em Unity, mas parei no menu. As duas versões estão aqui, nas pastas `Construct` e `Unity`.

## Como abrir

Construct: arraste o `Construct/O_que_e_PAAE_Com_Audio.c3p` pra dentro do Construct 3 no navegador (editor.construct.net). A pasta `Construct/O_que_e_PAAE_Com_Audio` é o mesmo projeto descompactado, pra dar pra ver os arquivos aqui no GitHub.

Unity: abra a pasta `Unity` pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.17f1.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
